# Plan AF2.2 — Luna Exact-Read Adapter and Capsule Isolation

**Status:** active — bounded adapter repair in Default mode; live run gated
**Priority:** prerequisite for resuming AF2.1 Luna control receipts
**Owner:** primary agent; Codex reviews all evidence

## Objective

Implement Option A with preventive OS isolation: a strict Codex
`command_execution` exact-read evidence adapter plus a Bubblewrap capsule
isolating the Luna control run, so real `codex exec --json` output can produce
proven read-only evidence without weakening any privacy, zero-cost, path,
citation, isolation, or mutation gate. The AF2.1 "accept only observed
`file_read` events" premise was false: no `file_read` item type exists in
`codex exec --json` output.

## Required behavior

- Run Luna inside a separate Bubblewrap capsule containing only the synthetic
  workspace and required runtime files. Mount only `README.md` and `AGENTS.md`
  as worker-readable task data.
- Use an isolated temporary Codex home containing only the minimum auth/config
  required, and invoke the pinned Codex CLI 0.147.0 with `--ephemeral`,
  `--ignore-user-config`, `-s/--sandbox read-only`, `--json`, `--output-schema`,
  and the exact Luna model and reasoning configuration.
- Keep provider networking available; expose no repository, protected paths,
  Git metadata, MCP, plugins, skills, or external writable directories.
- Translate only strictly parsed, completed read-only `command_execution`
  items into internal read evidence. Treat `reasoning` items as permitted
  protocol metadata and never persist their text.
- Accept only a tiny command grammar: one approved reader command and one
  declared file at a time, on exact relative paths inside the capsule.
- Reject pipelines, redirections, substitutions, globs, compound commands,
  absolute paths, traversal, writes, interpreters, and unknown commands.
- Preserve the `HASH_EMPTY` sentinel fix. Add source-version-pinned recorded
  Codex-shaped JSONL fixtures and negative tests before any live invocation.
- Stay in Default mode. No live run and no Goal-mode switch until the adapter
  and capsule are implemented, recorded real-shape fixtures tests pass,
  containment tests prove host/repo files unreadable from the capsule, all
  gates are green, and a dry-run adapter fixture produces exact-read evidence.
